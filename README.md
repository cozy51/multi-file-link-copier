# Multi File Link Copier

Obsidianの標準ファイルエクスプローラーで選んだファイルのWikiリンク、Vault内の相対パス、絶対パス、ファイル名をクリップボードにまとめてコピーします。メニューと設定は日本語です。

## インストール

1. Obsidianデスクトップ版（1.5.7以降）で、インストールするVaultを確認します。
2. Vault内の `.obsidian/plugins/multi-file-link-copier/` に、ビルド済みの [main.js](./main.js) と [manifest.json](./manifest.json) を入れます。Vaultで設定フォルダ名を変更している場合は、そのフォルダ内の `plugins` を使います。
3. Obsidianを再起動し、「設定」→「コミュニティプラグイン」で必要に応じて制限モードを解除し、**Multi File Link Copier** を有効にします。

## 使い方

1. 標準ファイルエクスプローラーでファイルを選びます。単一ファイルは直接右クリックできます。複数選択にはObsidian標準の操作を使います。離れたファイルは **Alt＋クリック**（macOSでは **Option＋クリック**）、連続範囲は先頭をクリックして末尾を **Shift＋クリック** します。
2. 選択済みの項目を右クリックし、**選択ファイルをコピー（N件）** から形式を選びます。1ファイルのときは **ファイルをコピー** と表示されます。
3. 貼り付け先でクリップボードのテキストを貼り付けます。出力はObsidianから受け取った順に1行1件です。

「右クリックメニューに表示する項目」で1形式だけをオンにすると、サブメニューを経由せず、右クリックメニューに **Wikiリンクをコピー（N件）** のような項目が直接表示され、1クリックでコピーできます（1ファイルのときは件数を表示しません）。Wikiリンクだけをよく使う場合に便利です。

開いているファイルのタブを右クリックしても、**ファイルをコピー** からそのファイルのリンクやパスをコピーできます。

ノート内のWikiリンク（`[[ファイルA]]` など）を右クリックしても、**ファイルをコピー** からリンク先ファイルのWikiリンクやパスをコピーできます。出力はリンク先ファイルから作り直すため、元のリンクに付いた見出し（`#`）や別名（`|`）は含まれません。リンク先のファイルがまだ存在しない場合は項目が表示されません。

| 形式 | 出力例 |
| --- | --- |
| Wikiリンク | `[[ファイルA]]` |
| 相対パス | `Documents/ファイルA.md` |
| 絶対パス（Windows） | `C:\Users\user\OneDrive\Obsidian\Documents\ファイルA.md` |
| ファイル名 | `ファイルA.md` |

Wikiリンクは表示名（`|` 以降の別名）を付けず、ファイル名だけで出力します。Markdownファイルでは拡張子を省略し、画像などのファイルでは拡張子を残します。Vault内に同名ファイルがあるなど、ファイル名だけで参照先を特定できない場合は `[[Documents/ファイルA]]` のようにフォルダを含めます（Vault直下のファイルは `[[/ファイルA]]`）。フォルダ自体や配下のファイルは件数とコピー対象から除外します。ファイルと同時に選択したフォルダからもメニューを開けます。フォルダだけの場合、メニュー項目は表示されません。

## 設定

「設定」→「Multi File Link Copier」で変更できます。設定はVaultごとに保存され、再起動後も保持されます。

| 設定 | 動作 |
| --- | --- |
| コピー形式の初期値 | 表示中の指定形式をサブメニューの先頭に置きます。初期値はWikiリンクです。 |
| コピー成功時の通知 | 成功通知の表示を切り替えます。コピー失敗時はこの設定に関わらず通知が出ます。 |
| 右クリックメニューに表示する項目 | 4形式の表示を個別に切り替えます。1形式だけオンにするとサブメニューなしで直接表示し、すべてオフにすると親メニューも表示されません。 |

## 対応環境と既知の制約

- デスクトップ版が対象です。絶対パスは `FileSystemAdapter.getFullPath()` から取得し、OS標準の区切り文字で出力します。WindowsのドライブやVaultの場所は固定していません。
- プラグインは標準のクリック操作を維持します。公式ヘルプに記載された飛び飛びの複数選択は、Windows／Linuxでは `Alt＋クリック`、macOSでは `Option＋クリック` です。検証したLinux版では `Ctrl＋クリック` で別タブが開きました。 [Obsidian公式ヘルプ](https://help.obsidian.md/plugins/file-explorer)
- 複数選択は公開APIの `files-menu`（1.4.10以降）、単一項目は `file-menu` で受け取ります。1.15.1の標準エクスプローラーでは、選択済み項目の右クリック時に複数選択を渡し、未選択項目の右クリック時はその項目を渡します。イベントが選択対象を渡さない場合、独自に選択を推測しません。 [Obsidian公開API](https://github.com/obsidianmd/obsidian-api/blob/master/obsidian.d.ts)
- 対象メニューの限定にはイベントの送信元 `file-explorer-context-menu`（標準エクスプローラー）と `tab-header`（タブの右クリック）、`link-context-menu`（ノート内リンクの右クリック）を使います。これらの文字列は公開APIの型で固定されていません。将来変更された場合はメニューが表示されなくなる可能性があります。DOM参照や選択のためのイベント横取りは行わず、購読はプラグインの無効化時にObsidianが解除します。
- 公開APIにサブメニュー作成機能がないため、メニュー生成の一箇所でのみ非公開の `MenuItem.setSubmenu()` を使います。このメソッドが利用できない場合、同じ右クリックメニューに件数の見出しと各形式を直接表示します。互換性の確認対象はObsidian 1.15.1です。 [Obsidian 1.15.1](https://github.com/obsidianmd/obsidian-releases/releases/tag/v1.15.1)
- Wikiリンクの構文で扱えない記号を含む場合や、Obsidianが参照先を特定できない場合はコピー全体を中止します。必要に応じて相対パスなどの形式を利用できます。コピー前にファイルの存在と種類を確認し、対象に移動、削除、置き換えが見つかった場合もコピー全体を中止します。ファイルの内容を読み書きせず、外部通信も行いません。設定値の保存にはObsidianのプラグイン設定APIを使います。

## ビルド

Node.js（22以降を推奨）とnpmで実行します。

```sh
npm ci
npm run build
```

`npm run build` は型チェックを実行してから `main.js` を生成します。型チェック単独では `npm run typecheck` を実行します。

## 動作確認手順

テスト用Vaultに、連続して表示される5ファイル（うち1つは `05 日本語🚀.md`）、別フォルダにそれぞれ置いた `A/同名.md` と `B/同名.md`、およびフォルダを用意します。コピー結果をプレーンテキスト欄に貼り付けて確認します。

| 項目 | 操作と期待結果 |
| --- | --- |
| 1. 単一ファイル | 1ファイルを右クリックします。「ファイルをコピー」が表示され、4形式それぞれで1行をコピーできます。 |
| 1b. タブ | 開いているファイルのタブを右クリックします。「ファイルをコピー」から4形式それぞれでそのファイルの1行をコピーできます。 |
| 1c. ノート内のリンク | ノート内の `[[ファイルA]]` を編集画面と閲覧画面でそれぞれ右クリックします。「ファイルをコピー」からリンク先ファイルの4形式をコピーできます。 |
| 2. 離れた2ファイル | Alt（macOSはOption）＋クリックで2ファイルを選び、選択済みの一方を右クリックします。件数は2件で、貼り付け結果は2行です。 |
| 3. 連続する5ファイル | 先頭をクリックし、末尾をShift＋クリックします。選択済みファイルを右クリックすると5件表示され、コピー結果に各ファイルが1回ずつ現れます。 |
| 4. 別フォルダの同名ファイル | `A/同名.md` と `B/同名.md` を選び、Wikiリンクを貼り付けます。フォルダを含む `[[A/同名]]` と `[[B/同名]]` で区別され、リンク先が一致します。 |
| 5. 日本語と絵文字 | `05 日本語🚀.md` の各形式を確認します。日本語や絵文字がそのまま貼り付けられます。 |
| 6. スペース | `01 note.md` の4形式を確認します。名前の途中のスペースが保持されます。 |
| 7. フォルダを含む選択 | ファイルとフォルダを同時に選び、選択済みフォルダを右クリックします。ファイルだけが件数と出力に含まれます。フォルダだけの選択では項目が出ません。 |
| 8. 選択の維持 | 2件以上を選び、右クリックの前後とコピー後で選択表示が維持されることを確認します。 |
| 8b. 1形式のみ表示 | 設定でWikiリンクだけをオンにし、2件選択して右クリックします。「Wikiリンクをコピー（2件）」が直接表示され、クリックで2行コピーできます。1ファイルやタブでは「Wikiリンクをコピー」と表示されます。 |
| 9. 設定の再読み込み | 初期値、通知、メニュー表示を変更し、プラグインを無効化して有効化します。設定とメニューに変更が反映されます。 |
| 10. 再起動 | Obsidianを終了して同じVaultを開きます。設定が保持され、ファイルを選び直すと同じ操作でコピーできます。 |

Windowsでは、絶対パスが実際のVaultのドライブと保存場所を指し、区切り文字が `\` であることを確認します。macOSではOptionによる飛び飛び選択と、絶対パスが `/` 区切りで出力されることを確認します。
